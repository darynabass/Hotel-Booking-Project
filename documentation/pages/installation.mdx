## Requirements

To use the Hotel Booking Python SDK, you need:

- Python 3.10 or newer
- pip package manager

## Download the SDK

Clone the SDK repository from GitHub:

```bash
git clone https://github.com/YOUR_USERNAME/hotel-booking-python-sdk.git
```

Navigate to the project directory:

```bash
cd hotel-booking-python-sdk
```

## Install the SDK

Install the package using pip:

```bash
pip install .
```

## Usage Example

```python
import openapi_client
from openapi_client.api import hotels_api

configuration = openapi_client.Configuration(
    host="http://localhost:8000/api/v1"
)

with openapi_client.ApiClient(configuration) as api_client:
    api = hotels_api.HotelsApi(api_client)
    hotels = api.get_hotels()

    print(hotels)
```

## API Specification

The API specification is written in OpenAPI 3.0.3 format and is available in the main project repository.
