## Project Description

Hotel Booking API is an educational project developed as part of a practical assignment.

The project provides a REST API specification for managing hotels and hotel rooms.

## Author

Software Engineering student.

## Technologies

- YAML
- OpenAPI Generator
- Zudoku
- GitHub

## Project Purpose

The purpose of this project is to design a REST API, generate a Python SDK client, and create interactive API documentation.
